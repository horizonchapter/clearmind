# Changelog

## 1.1.0 (2026-11-21)
- New section 12, "Readable by a reader whose attention drifts": answer first, short labeled blocks, numbered steps, about 5 items per list (never dropping a relevant item), fixed report order (Done, In progress, On you, Still open), one next action, user can switch it off with "normal mode". Former section 12 "Before sending" is now 13 and checks readability.
- Inspired by the MIT-licensed [i-have-adhd](https://github.com/ayghri/i-have-adhd) by ayghri (rewritten, no text copied).
